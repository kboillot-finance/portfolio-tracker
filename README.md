# Investment Portfolio Tracker

Excel-based portfolio management system with multi-currency support and real-time market data integration.

![Excel](https://img.shields.io/badge/Excel-217346?style=flat-square&logo=microsoft-excel&logoColor=white)
![License](https://img.shields.io/badge/License-MIT-blue.svg?style=flat-square)

## Overview

Professional investment tracking tool designed for managing multi-currency stock portfolios. Features automated data retrieval, currency conversion, and comprehensive performance analytics.

## Key Features

**Portfolio Management**
- Real-time stock prices via Excel Stock Data Types
- Automatic EUR/USD currency conversion
- Live exchange rate integration
- Industry classification and sector analysis

**Performance Tracking**
- Daily P&L monitoring (absolute and percentage)
- Position-level gain/loss calculation
- 12-month historical performance
- Portfolio composition by industry

**Transaction Management**
- Complete buy/sell transaction ledger
- Historical exchange rate tracking
- Automated calculations and updates

## Technical Implementation

**Core Formulas**
- Dynamic array formulas for automatic data expansion
- Multi-currency price normalization
- Conditional formatting for performance visualization
- Error handling for ETFs and missing data

**Data Integration**
- Excel Stock Data Types (Refinitiv)
- Real-time market data
- Automated industry classification

## System Requirements

- Microsoft Excel 365 or Excel 2021+
- Internet connection for live data
- Stock Data Types feature enabled

## Installation

1. Download `Investment-Tracker.xlsx`
2. Open in Microsoft Excel

## File Structure

**Dashboard Sheet**
- Current holdings overview
- Performance metrics
- Industry allocation analysis

**Ledger Sheet**
- Transaction history
- Date, ticker, type, units, price
- Currency and exchange rate tracking

## Use Cases

- Personal portfolio management
- Multi-currency investment tracking
- Financial modeling demonstrations
- Excel proficiency showcase for finance roles
